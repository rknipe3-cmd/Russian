# Russian
Русский: Crash Course

A self-contained study app for brushing up on Russian before an EOI prueba de nivel. Built as a single HTML file, hosted on GitHub Pages.

What's in it#

Vocab — ~100 words across 8 categories (daily life, family, work, describing photos, adjectives, colours, time/place, connectors). Tap to reveal translations.
Verbs — 23 essential verbs with full conjugation tables, aspect labels, and notes on irregularities and consonant mutations.
Cases — All 6 cases with endings, usage rules, and examples.
Preps — Prepositions grouped by function (location vs direction, genitive, dative, instrumental, time, "about"), each showing case governance and example sentences.
Phrases — Ready-made sentence patterns for the oral exam: about me, family, work, describing photos, opinions.
Quiz — 15-question multiple choice on vocab, verbs, cases, or prepositions.
Setup

Hosted via GitHub Pages. Just index.html and manifest.json in the root.

Works offline once loaded. Add to home screen on mobile for a PWA experience.
